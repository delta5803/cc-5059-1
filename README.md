# 段落配乐引擎（交互式段落调度）

把自制主题、过渡、收束短谱组织为**有条件的连接图**；外部情境（情绪）改变时，引擎在满足**乐句边界、拍号、和声**要求的位置转入新段落。输入不是整首预录音频——系统逐小节真实调度音符与时值，处理弱起、跨界延音与上一段尾部。

## 图形入口（段落配乐界面）

```bash
npm run serve        # 然后浏览器打开 http://localhost:8080/
```

（等价：`python3 -m http.server 8080` 等任意静态服务器，入口为 `index.html`。）

界面包含：

- **段落编曲**：全部主题/过渡/收束段卡片（调性、拍号、速度、弱起、准备拍），点击看乐句钢琴卷帘，「试听该段」播放引擎实际渲染的一遍循环；情绪按钮现场切换。
- **调度状态**：当前乐句/小节/循环、待定出口（各情境的最早可行出口或不可达原因）、排队请求、最近承诺的调度事件、调度日志。
- **结果区**：情境序列（可重放）→「渲染并校验」后呈现**过渡节奏**（每条计划的路径、出口、锁定点、逐项接点检查 ✓/✗、被抢占/已执行）与**实际配乐**（渲染事件钢琴卷帘），校验结论与**异常**（不可达、已收束等）在此提示；可回放渲染结果、载入示例情境、导出/导入情境 JSON。
- **段落连接图**：声明边及其乐理可行性——不存在"任意两段都能直连"。

## 辅助命令行

```bash
npm test                              # 引擎规则测试（21 例）
node cli/score-cli.mjs validate       # 体检曲谱与连接图
node cli/score-cli.mjs sections       # 段落清单
node cli/score-cli.mjs links          # 声明连接与可行性
node cli/score-cli.mjs demo           # 运行内置示例情境（覆盖全部规则）
node cli/score-cli.mjs run s.json     # 运行情境文件（--json 输出完整事件）
```

情境文件格式：`{"start": "theme_dawn", "until": 164, "requests": [{"t": 6, "mood": "tense"}]}`，
`mood ∈ calm / tense / heroic / drift / end`。

## 调度规则（显式）

1. **出口**：仅当前主题段声明为可出的乐句终止拍。请求在时间 `t` 到达时，出口 `E` 可行当且仅当 `E - 准备拍 ≥ max(t, 已承诺前沿)`——决策点之后到达的请求对该出口无效，**顺延**到下一可行出口；事件只追加不修改，**绝不生成倒退的事件时间**。
2. **出口变体**：出口乐句的末尾小节替换为终止变体（和声随之改变），因此准备拍 ≥ 1 小节，变体在承诺前沿经过前必须已决定。
3. **抢占 / 延后**：已有待定过渡时来了新情境——锁定点（`E - 准备拍`）之前到达则**抢占**：作废未发声的旧计划按新情境重排（请求当前情绪 = 撤销过渡留在原段）；锁定点之后到达（或过渡/收束进行中）则**延后**入队，过渡落地后出队重排，队列**后到者优先**。
4. **弱起**：目标段的弱起音铺在旧段最后一小节内（各段弱起长度可不同），须与实际发声的旧段和声或目标和声协和，否则该出口不可用。
5. **跨界延音 / 尾部**：旧段出口小节的延音按声明拍数越界发声、尾部事件在接点后继续，均须与进入段起始和声协和；**不截断**——不协和的出口改选其他乐句出口。
6. **最后一拍对齐**：接点前最后一拍的实际发声和声 = 旧段（变体）终止和弦，接点后 = 新段起始和弦；校验器逐项核对。
7. **连接图**：只有声明的边可通行；直接边须通过调性兼容（同调/关系大小调/五度关系），不兼容调性必须经声明的过渡段（如 `潮 → 过渡·烬 → 歌`）；无路径即**不可达异常**（如「游离」），音乐不中断。
8. **收束**：收束段播完引擎停止（尾部延音收尾），之后的请求以异常拒绝。

## 校验（计划路径 = 听闻结果）

`src/verify.js` 独立复核渲染事件流：事件时间非负、和声轨连续单调、段落起点递增、小节长度合拍号、每个接点的终止→起始和弦兼容、弱起/延音/尾部逐项协和、被抢占计划除外的**计划路径与听闻段落序列一致**。界面结果区与 `demo/run` 均输出校验结论。

## 结构

```
index.html            图形入口（编曲试听台）
src/score-data.js     自制曲谱：主题/过渡/收束 + 连接图声明
src/theory.js         音高/和弦/调性兼容规则
src/graph.js          连接图展开与寻路（主题不可中转、过渡不可成链）
src/scheduler.js      调度引擎（出口/准备/抢占/延后/弱起/延音/尾部）
src/verify.js         听闻结果校验器
src/render.js         情境序列离线渲染（界面结果区与 CLI 共用）
src/player.js         简化音色（三角波/正弦波，仅发声，不参与运算）
src/ui.js             界面逻辑
cli/score-cli.mjs     辅助命令行
test/engine.test.mjs  规则测试
```

音色从简是刻意的：段落关系、出口选择、和声对齐全部参与实际运算，不靠淡入淡出掩盖乐句截断。
